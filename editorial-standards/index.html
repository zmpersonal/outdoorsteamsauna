Editorial and data standards

Claims should be traceable to a source or disclosed calculation.

Source hierarchy

  1. Government datasets and technical documentation.
  2. Current manufacturer manuals and official specifications.
  3. Derived calculations whose inputs and formulas are published.
  4. Secondary sources only when a primary source is unavailable.

Data publication rules

  • Missing values remain missing; they are not converted to zero.
  • State averages are labeled as state averages.
  • Modeled values are labeled as estimates.
  • Rankings exclude records that lack the required field.
  • Material method changes receive a version number and changelog entry.

Corrections

Material errors are fixed in the dataset and documented with the date, affected field and nature of the change.

Commercial independence

No retailer payment, affiliate relationship, price or preference changes a climate score, cost index, research table or city rank. Commerce is disclosed and isolated on a dedicated page.

Safety boundary

Planning information is not electrical, engineering, medical, code or permitting advice.

OutdoorSteamSauna.com

An independent climate, electricity-cost and planning reference for outdoor traditional sauna projects. Estimates are for comparison—not electrical, structural or code approval.
